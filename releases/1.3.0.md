# SendToSMB 1.3.0

- 设置页新增“在后台继续运行”复选框，默认关闭并保存选择。勾选后，上传 / 下载通过 Android 前台服务在锁屏、切换应用或关闭任务界面后继续；通知栏显示进度、平均速度，并提供打开传输页及取消全部入口。
- 传输结束、取消或达到系统后台服务时限后释放唤醒锁、Wi-Fi 锁和后台 SMB 连接。上传期间保留所选文件的读取授权，完成后释放本次新增的授权。
- 首页连接 SMB 后继续显示“连接，让文件触手可及”及文件夹 / Wi-Fi 宣传图案。
- 每个任务显示实时速度，完成记录保存平均速度。传输页固定顶栏显示整批平均速度，包含小文件准备、切换及队列等待耗时；短任务完成后也能查看速度。
- 已完成 Release / Debug / AndroidTest APK 构建、13 项 JVM 单元测试和 Lint（无错误）。后台传输、通知取消及界面仪器测试已新增并编译通过；本次无连接手机，Android 15 模拟器缺少硬件加速且软件模式启动崩溃，未完成设备运行验收。

包名 `com.zlight.sendtosmb`，版本 `1.3.0 / 6`，最低 Android 8.0。延续 1.2.0 的本机 Android 调试密钥签名，可覆盖升级此前使用同一签名的安装包。安装包作为 GitHub Release 附件发布，校验值见 `SHA256SUMS.txt`。

强制停止或系统终止进程仍会中止传输；不提供断点续传。
