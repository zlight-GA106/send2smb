# 1.1.2 调试安装包

`SendToSMB-1.1.2-debug.apk` 是 2026-09-09 在 Redmi Android 16 测试机验证并安装的 Debug 构建，最低 Android 8.0。

1.1.2 修复已关闭的 SMB 共享对象被误判为仍然连接、点击项目后偶发操作失败的问题；失效连接会被丢弃并自动重连。传输页新增“指定保存目录”，授权后后续下载直接保存到该目录，选择结果加密保存在本机，也可以恢复为每次询问。文件传输、生命周期、真实共享只读与界面测试结果见 `docs/TESTING.md`。

安装包使用本机 Android 调试签名，适合此次测试和本机安装，正式发行需另配发布签名。APK 不提交 Git，校验值见 `SHA256SUMS.txt`。
