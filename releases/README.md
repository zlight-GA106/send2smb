# 1.0.0 调试安装包

`SendToSMB-1.0.0-debug.apk` 是 2026-09-06 在 Redmi Android 16 测试机验证并安装的 Debug 构建，最低 Android 8.0。

支持 Fluent 2 风格文件管理、自定义 SMB 地址、加密保存凭据、前后台连接管理、容量、流式双向传输和手机/平板自适应布局。文件传输、生命周期、真实共享只读与界面测试结果见 `docs/TESTING.md`。

安装包使用本机 Android 调试签名，适合此次测试和本机安装，正式发行需另配发布签名。APK 不提交 Git，校验值见 `SHA256SUMS.txt`。
