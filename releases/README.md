# 1.1.0 调试安装包

`SendToSMB-1.1.0-debug.apk` 是 2026-09-09 在 Redmi Android 16 测试机验证并安装的 Debug 构建，最低 Android 8.0。

1.1.0 将首页和文件管理拆成独立栏目，增加文件搜索、加密持久传输历史和再次下载，并在临时权限拒绝或会话过期时重建只读连接。连接步骤调整为“在同一局域网”“发起连接并保存凭据”“访问你的文件”。文件传输、生命周期、真实共享只读与界面测试结果见 `docs/TESTING.md`。

安装包使用本机 Android 调试签名，适合此次测试和本机安装，正式发行需另配发布签名。APK 不提交 Git，校验值见 `SHA256SUMS.txt`。
