# SendToSMB 1.2.0

- 不再强制要求检测到 Wi-Fi 才能发起连接：即使系统未识别到无线或有线局域网（例如通过 VPN、USB 网络共享访问 SMB 服务器），也可以直接尝试连接；局域网断开时不再自动关闭现有会话，由 SMB 操作自行报错和重试。
- 新增“设置”页。E Ink 模式开启后整个应用以灰度渲染，适合电子墨水屏设备；开关与更新服务地址保存在本机私有设置中，可随时更改。
- 设置页新增 EasyUpdate 更新：可填写自托管 EasyUpdate 服务地址（默认 `http://192.168.95.55:19910`），检查新版本、查看版本说明、下载并校验 SHA-256 后调用系统安装器安装；检查更新后同时向服务上报匿名设备心跳。
- 应用版本号提升为 `1.2.0 / 5`，并加入“安装未知来源应用”权限声明与 `FileProvider`，用于安装更新包。

此版本已作为正式版发布到 EasyUpdate 服务（应用 ID 6，版本 `1.2.0 / 5`），公开接口可查询与下载。安装包为最低支持 Android 8.0 的 release 构建（未混淆），按所有者选择使用本机 Android 调试密钥签名，可覆盖升级调试版；对外正式发行前仍应改用所有者自有发布签名。
