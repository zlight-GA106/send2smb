# SendToSMB 1.5.0

- 上传、下载新增断点续传。传输页可暂停、继续和确认放弃；网络中断、应用被关闭或进程重新启动后，保留加密任务记录和已有片段，返回传输页即可继续。
- 上传使用稳定的任务临时文件，验证已有前缀后从实际偏移继续。源文件和远程最终内容经过 SHA-256 校验后再重命名提交；目标内容冲突时拒绝覆盖。即使远程提交成功后连接断开，也能识别已经完成的文件。
- 下载保留本机片段，续传前核对远程大小、修改时间、内容身份和已有前缀；完整校验后，通过系统保存目录中的临时文件、读回校验和重命名提交。文件夹保存固定清单及子文件完成记录，避免重复生成已下载文件。
- 排队任务在获得传输连接前即持久化；来源授权保留至完成或放弃，不支持持久授权的来源先缓存。更改当前连接的服务器或账号时关闭旧会话，避免复用错误连接；删除后重建相同身份的连接也可继续任务。
- 后台通知改为“暂停全部”，系统后台时限到达时也保留断点。清空历史不会移除可续传任务；放弃续传保留已完成文件。
- 兼容只允许读取内容、拒绝读取文件属性的 NAS；续传速度排除已有片段，避免恢复时虚增速度。72 项本机自动测试全部通过，Release / Debug / AndroidTest APK 构建及 Lint 通过，无跳过。

下载缓存及不支持持久授权的上传来源需要足够的本机存储；校验阶段会额外读取数据。系统文档提供方需要支持读取、创建及重命名，旧版已删除的片段无法恢复。任务不会在进程重启后自行传输，需点击“继续传输”。本次没有测试手机，设备界面与真实文档提供方测试仅编译；本机隔离 SMB 和文件系统文档适配器用于验证续传及故障恢复。

包名 `com.zlight.sendtosmb`，版本 `1.5.0 / 8`，最低 Android 8.0。沿用已有签名，可覆盖升级此前使用相同签名的版本。
