# SendToSMB 1.4.0

- 新增记事本式纯文本编辑器。在 SMB 文件夹的“文件操作”菜单新建 TXT，或点开现有 `.txt`；先缓存到本机，编辑期间不持续占用 SMB 连接。首页提供本地编辑与草稿恢复入口。
- 自动识别并保留 UTF-8、UTF-8 BOM、GBK、UTF-16 LE / BE BOM；保留 CRLF、LF、CR 及混合换行。未改内容不重写，不能无损识别或编码的内容会阻止保存，避免替换字符、擅自转换换行和添加 BOM。
- 提供查找 / 替换 / 全部替换、撤销 / 重做、跳转行、字数 / 字符 / 行数、字体大小与行距、自动换行、只读及另存为。原生触摸选择、复制 / 剪切 / 粘贴 / 全选工具栏、方向键和外接键盘快捷键方便移动端使用。
- 修改后标题显示 `●`；本机恢复草稿与远程保存分别提示。自动保存可关闭、离开页面时保存或每 30 秒保存。草稿先写临时文件并 fsync，再原子替换；SMB 保存先核对远程内容，再写同目录临时文件、flush 并重命名替换。遇到远程冲突或异常保留草稿，同名另存为不会覆盖其他文件。
- 支持 Android“打开方式”、接收分享文本 / TXT、系统文档选择器打开与另存到 Documents 等位置，以及分享文本文件。设备文档另存为副本并读回校验，本地编辑无需联网。
- 大文件磁盘分页处理：源文件最大 256 MiB、约 64K 字符一页、单页最多 256K 字符；跨页查找和行号跳转，全文件替换使用磁盘撤销记录。查找内容最长 4096 个字符。
- Release / Debug / AndroidTest APK 构建和 Lint 通过。36 项 JVM 自动测试通过，其中 5 项通过本机隔离 SMB 服务验证缓存、临时文件替换、冲突保护、无变化保存和另存为。此次无测试机，新增触摸编辑和文件操作界面测试只编译，未做设备运行验收。

包名 `com.zlight.sendtosmb`，版本 `1.4.0 / 7`，最低 Android 8.0。沿用此前安装包的签名，可覆盖升级使用同一签名的旧版。APK 作为 GitHub Release 附件发布，校验值见 `SHA256SUMS.txt`。
