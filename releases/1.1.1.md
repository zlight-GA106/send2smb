# SendToSMB 1.1.1

- 首页恢复原有文件概览，只显示 SMB 地址、容量和当前位置，不显示搜索、操作栏或文件列表。
- 底部“文件管理”成为独立页面，集中显示路径导航、搜索框、文件操作栏和文件列表。
- 传输记录默认加密保存在本机，下载记录支持再次下载，并可切回原连接。
- 目录读取遇到失效会话或临时权限拒绝时自动重连一次；下载在服务器拒绝读取属性时使用最小读取权限。
- 首页引导卡移除说明性文字；连接步骤改为“在同一局域网”“发起连接并保存凭据”“访问你的文件”。

APK 为已在 Redmi Android 16 测试机安装验证的 Debug 签名构建，最低支持 Android 8.0。
